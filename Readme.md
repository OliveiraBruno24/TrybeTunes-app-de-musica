# TrybeTunes

Aplicação de música em React: busque um artista, abra os álbuns, ouça a prévia de cada faixa e salve suas favoritas.

> Projeto desenvolvido durante o curso de Desenvolvimento Web da [Trybe](https://www.betrybe.com/) (2023).

## Funcionalidades

- Login com nome de usuário
- Busca de álbuns por artista (API do iTunes)
- Página do álbum com prévia de 30 segundos de cada música
- Favoritar e desfavoritar músicas, com página de favoritas
- Perfil do usuário com edição

## Stack

React 18 · TypeScript · React Router · Vite · Vitest · React Testing Library

## Como rodar

```bash
npm install
npm run dev
```

Testes:

```bash
npm test
```
